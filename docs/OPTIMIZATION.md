## 验证范围

- `npm test`：14 项回归测试，覆盖地址校验、跳转、固定地址连接、流式体积 / 时间限制、浏览器代理拒绝内网、三档采样、Ajax 金额、文案反例、证据分级、多样本聚合、未知币种和本地 / 生产模块一致性。
- `npm run build`：Vite 生产构建。
- `npm run test:ui`：真实 Chrome 渲染隔离数据，检查 28 条策略、3 个样本 URL、筛选、表格 / 看板、视图持久化、详情与图片放大、390px 无页面横向溢出、普通购物车行不是推荐、带额外商品的推荐卡可识别、内网输入被拒绝。
- 真实静态扫描：`silixwear.com`，识别 USD，读取 2 / 3 个商品页，另一页失败如实记录，静态结果没有强证据。
- 真实匿名浏览器：Silix FlexSupport Compression Socks，真实点击将数量从 0 改到 1，再将数量改为 2，进入结账入口但未填写信息或提交订单。加载后的抽屉保存截图；其他文字信号仍为观察状态。运行约 42 秒。

## 重要边界

- 没有新增依赖，也没有修改 Vercel、Railway、Docker、密钥或环境配置。
- 尚未更新生产 Vercel 或远程 Worker。目标云环境中的 Chromium 启动、资源配额和连通性需要在发布时验证。
- 仅补充了一个有操作证据的真实策略案例；其余参考明确标为待验证，不冒充已完成的案例库。
- 优先级、App / 开发 / 难度标签是实施参考，不是量化增长承诺。没有因一个站点成功而声称所有 Shopify 店铺都可完整检查。
