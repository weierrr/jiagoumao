# 加购猫

面向 Shopify 独立站卖家的客单价策略诊断工具。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

项目会读取公开可访问的 Shopify 店铺或商品页面，输出客单价策略线索、证据出处和可执行的增长建议。

## 诊断与策略视图

- 诊断报告和策略库提供表格 / 横向看板；视图选择会保存到当前浏览器。
- 可以按页面、类型、状态、App 与难度筛选，并按参考优先级或难度排序。
- 点击策略打开证据、配置说明、适用场景和验证指标。参考优先级不是经营效果评分。
- 静态页面和源码命中为“有线索”；浏览器中实际可见为“已观察到”；只有明确的动作触发才是“已验证”。无法完成的阶段为“无法确认”。
- 低 / 中 / 高价格带样本会实际请求商品 HTML；失败样本和失败阶段保留在报告中。
- 价格以读取到的原币种展示；币种未知时明确标记，不默认美元。
- 策略库中的 Silix 购物车抽屉案例保存了 2026-09-26 匿名加购场景截图。其他品牌链接标为待验证参考，不等同于场景证据或收入效果。

## 代码与验证

本地服务器和 Vercel API 共用 `lib/analyze.mjs`、`api/journey.mjs`。浏览器 Worker 与 API 共用 `lib/journey-result.mjs`，保留所有样本的失败记录、证据来源和检查边界。

```bash
npm ci
npm test
npm run build
npm run test:ui
```

`test:ui` 启动独立的本地生产预览和匿名 Chrome，用隔离样本测试真实 UI 交互，不访问真实商店。macOS 默认使用系统 Google Chrome；Linux 默认 `/usr/bin/chromium`，也可在运行时设置 `CHROME_EXECUTABLE_PATH`。桌面 / 手机截图输出在临时目录。

静态 HTTP 抓取逐跳检查 DNS 和 IPv4 / IPv6 地址，并固定连接到已检查的地址；浏览器通过本地安全代理发起请求，避免跳转或子资源访问内网。读取体积和时间设有上限。

生产发布时需要同时更新 Vercel 应用及已配置的浏览器 Worker 代码；无需增加依赖或更改环境变量。发布前仍需在目标环境验证 Chromium 启动、Worker 连通性与实际店铺行为。本地成功不代表生产已发布。
